# CamJam Control

This repository contains a ROS2 package for reading sensor data from the CamJam Edukit #3 robot using a Raspberry Pi. It was tested using ROS2 Jazzy on a Raspberry Pi 2W running Ubuntu 24.04, but other software versions or Raspberry Pi editions may also work.

It is intended to run as a ROS 2 package and is used by the [`camjam_control`](https://hithub.com/mikelikesrobots/camjam_control) package, which launches the sensors in its launch file.

For instructions on how to use this package, see [my blog post](https://mikelikesrobots.github.io/blog/raspi-camjam-ros2).
